# nflcteprev
This repository contains the main code and summary level data used in the bias-adjusted NFL CTE prevalence paper published by Boston University in 2026.

"Main functions.R" contains R code with three custom functions used to create the results in this paper. Most crucially, the "sratio" function calculates the selection ratios that form the basis of these analyses. All three functions are commented in detail in the program.

"tab3_results.Rda" contains an R list with three data frame items: sr_data, cte_data, and dem_data. These summary level data can be used to recreate Table 3 in the paper. Each data frame has 10 rows corresponding to the main analysis followed by the nine sensitivity analyses. Each data frame has 1,000 columns corresponding to the different iterations. The sr_data item contains selection ratios, the cte_data item contains adjusted CTE prevalence values corresponding to the selection ratio from the same iteration, and the dem_data item contains adjusted dementia prevalence values corresponding to the selection ratio from the same iteration.

Deidentified individual-level analytic data and a data dictionary defining each field used in the analysis will be made available to qualified investigators upon reasonable request. Because the study links neuropathologic data from the UNITE brain bank with mortality and demographic data derived from restricted sources, access to individual-level data will require review and approval by the study investigators and completion of a signed data access agreement. Data will be shared only for research purposes consistent with the consent, institutional review board approvals, data-use restrictions, and privacy protections governing the source datasets. Requests should be directed to Ann C. McKee, MD, at amckee@bu.edu, or to the corresponding author Yorghos Tripodis, PhD, at yorghos@bu.edu. Requests for record-level data will be reviewed against documented criteria within 60 days.
